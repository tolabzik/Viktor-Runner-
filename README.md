# VIKTOR RUNNER — IRI Office 3.1

Бесконечный офисный экшен-платформер в браузере. Герой — Виктор с предоставленной фотографии. Без CDN, регистрации и сторонних игровых сервисов.

## Версия 3.1 — IRI Office + «Поддержка»

- Три сменяемые локации: **5 этаж · офис ИРИ**, **6 этаж · богатый офис**, **переговорки ИРИ**. Локации меняются автоматически по секторам или вручную клавишей **L / ЛИФТ**. В декорациях используется фирменная вывеска ИРИ.
- Оружие: **пистолет**, **Калашников**, **рогатка**, **швабра**. Для стрелкового оружия добавлены отдельные отдача, положение рук, вспышка, гильзы; рогатка стреляет по дуге, швабра работает как ближний бой.
- **SHIFT / Z** полностью останавливает Виктора. После отпускания он продолжает бег. Приседание имеет отдельную анимацию с согнутыми ногами и наклоном корпуса.
- В конце офисных секций появляется лёгкий мини-босс **«Поддержка»** по предоставленному изображению: 8 HP, медленное движение, заметная подготовка атаки. За победу выпадают премия и шабашка.

## Обновление на сервере

```bash
cd /opt/viktor-runner
git pull --ff-only
docker compose up -d --build
```

Не используйте `docker compose down -v`: `-v` удалит том с таблицей рекордов.

## Управление

Пробел / W / ↑ — прыжок. X / J / мышь — атака. 1–4 или Q — оружие. A / D или ← / → — скорость. SHIFT / Z — остановиться. S / ↓ — присесть. L — сменить локацию через лифт. P / Escape — пауза, M — звук.

## Доска почёта

Общие рекорды хранятся в SQLite в постоянном Docker volume. Результат пересчитывается сервером. Формула: `метры + монеты × 25 + противники × 100 + шабашки × 500 + премии × 1000`.
