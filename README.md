# VIKTOR RUNNER — IRI Office 3.1

Бесконечный офисный экшен-платформер в браузере. Герой — Виктор с предоставленной фотографии.

## 3.1

- Локации: **5 этаж · офис ИРИ**, **6 этаж · богатый офис**, **переговорки ИРИ**. Автосмена по секторам и ручной **L / ЛИФТ**.
- Оружие: **пистолет**, **Калашников**, **рогатка**, **швабра**. Добавлены отдача, вспышка, гильзы, отдельная анимация рогатки и ближний бой шваброй.
- **SHIFT / Z** — полностью остановиться; после отпускания бег продолжается. **S / ↓** — анимированное приседание.
- Лёгкий мини-босс **«Поддержка»**: 8 HP, медленные телеграфируемые атаки розовой битой; за победу — премия и шабашка.
- Сохраняются общая таблица лидеров, SQLite-рекорды, офисные персонажи и Docker Compose.

## Обновление уже развёрнутого сервера

```bash
cd /opt/viktor-runner
git pull --ff-only
docker compose up -d --build
docker compose ps
curl -fsS http://10.1.16.140:8082/api/health
```

Не используйте `docker compose down -v`: ключ `-v` удалит volume с рекордами.

## Управление

Пробел / W / ↑ — прыжок. X / J / мышь — атака. 1–4 или Q — оружие. A / D или ← / → — скорость. SHIFT / Z — остановиться. S / ↓ — присесть. L — лифт / смена локации. P / Escape — пауза, M — звук.
